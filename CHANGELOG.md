# Changelog

All notable changes to **Build 53 (ModulaUI — React CSS Modules Component Library)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-07-30

### Added
- Integrated **Scoped Breadcrumb Navigation Trail Component (`Breadcrumb.jsx`, `Breadcrumb.module.css`)**.
- Added accessible navigation trails with icon prepends, customizable separators (`/` or `›`), and active page highlights.

## [1.9.0] - 2026-07-30

### Added
- Integrated **Scoped Slider Range Control Component (`Slider.jsx`, `Slider.module.css`)**.

## [1.8.0] - 2026-07-30

### Added
- Integrated **Scoped Alert Callout Banner Component (`Alert.jsx`, `Alert.module.css`)**.

## [1.7.0] - 2026-07-30

### Added
- Integrated **Scoped Dropdown Select Menu Component (`Select.jsx`, `Select.module.css`)**.

## [1.6.0] - 2026-07-30

### Added
- Integrated **Scoped Tooltip Hover Popup Component (`Tooltip.jsx`, `Tooltip.module.css`)**.

## [1.5.0] - 2026-07-30

### Added
- Integrated **Scoped Avatar & Avatar Group Component (`Avatar.jsx`, `AvatarGroup.module.css`)**.

## [1.4.0] - 2026-07-30

### Added

## [1.3.0] - 2026-07-29

### Added

## [1.2.0] - 2026-07-29

### Added

## [1.1.0] - 2026-07-29

### Added
- Integrated **Scoped Modal Overlay Component (`Modal.jsx`, `Modal.module.css`)**.

## [1.0.0] - 2026-07-29

### Added
- Initial release of **ModulaUI React Component Library** (Build 53).
- Implemented **5 Reusable Scoped Components** (`Button`, `Card`, `Badge`, `Accordion`, `Toast`).
- Built interactive showcase playground in `App.jsx` with `App.module.css`.
- Added master 404-line `AGENTS.md` and MIT `LICENSE`.
